# dotfiles-personal

Personal profile overlay repository for [`dotfiles`](https://github.com/diegolramirez/dotfiles), cloned automatically to `~/Developer/dotfiles/dotfiles-personal` (symlinked at `~/.config/dotfiles-overlay`) by `chezmoi` on `diegolramirez@laplace-mac` and personal Linux hosts.

## Contents
- `Brewfile` — Personal CLI tools and casks (`gh`, `exiftool`, `uv`, `pyenv`, `libpq`, `antigravity-cli`, `claude-code`).
- `zsh/` — Personal shell helpers (`libpq` on `PATH`).
- `git/` — Personal Git author identity (`Diego Ramírez-Milano <diegolramirezmilano@gmail.com>`).
- `ssh/` — Personal GitHub and homelab (`laplace-paris`) SSH host definitions.
- `vscode/` — Personal VS Code overlay (`claudeCode.*`, personal `cSpell.userWords`, `anthropic.claude-code`).
- `claude/` — Personal Claude Code model/effort preferences and instructions.
- `t3/` — Personal T3 Code provider configuration (`antigravity`, `claudeAgent`, `codex` disabled).
- `skills/` — Personal cross-agent `SKILL.md` skills.
